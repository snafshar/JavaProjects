# NumberQuest

A small terminal number-guessing game for Java 17+. The program chooses a secret number and gives the player a limited number of guesses.

## Run

```bash
javac NumberQuest.java
java NumberQuest
```

## Rules

- The secret number is between 1 and 100.
- Enter one whole-number guess per turn.
- The game says whether the secret is higher or lower.
- Invalid input does not consume a guess.
- The game ends when you find the number or run out of attempts.
