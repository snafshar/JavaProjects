# NumberQuest: Extension Challenges

1. Add three difficulty settings with different ranges and attempt limits.
2. Count invalid inputs separately from valid guesses.
3. Add a replay prompt without duplicating the game loop.
4. Move secret-number generation and guess evaluation into a separate class.
5. Write unit tests for boundary values and win/loss conditions.
6. Keep user-facing messages clear when input is empty or outside the permitted range.
