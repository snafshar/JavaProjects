# Algorithm Complexity Review

For each implementation, record:

- Input size variable(s).
- Best, average, and worst-case assumptions.
- Time complexity.
- Additional space complexity.
- Whether recursion depth can grow with input size.
- Whether input order affects behavior.
- Whether integer overflow can change correctness.
- Whether the implementation has a simpler library equivalent.

Verify the analysis against loops, recursive calls, and data-structure operations. For example, a hash map's average lookup is constant time, but worst-case guarantees differ.
